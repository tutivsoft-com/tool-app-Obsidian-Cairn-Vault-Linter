# Cairn Vault Linter

Version: 3.4.34

Offline vault health report for broken links, duplicate references, block IDs, and dangling stubs.

## Pricing and usage

The verified active one-time Paddle offers are:

| Price | Included native units |
| ---: | ---: |
| $1 USD | 100 credits |
| $10 USD | 1,000 credits |

Paid usage is measured in Cairn credits; the plugin reserves and reports units for each confirmed task. The plugin loads current price and product details from Constance/Paddle and displays the confirmed amount and native units before checkout. Prices and availability shown in Obsidian are current at purchase time.

## Installation

In Obsidian, open **Settings → Community plugins → Browse**, search for **Cairn Vault Linter**, install it, and enable it.
